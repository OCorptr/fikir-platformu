# Geleceğin Fikri Frontend

React, TypeScript ve Vite tabanlı statik frontend uygulamasıdır.

## Komutlar

```powershell
pnpm install
pnpm dev
pnpm typecheck
pnpm build
```

Geliştirme sunucusu `/api` isteklerini varsayılan olarak `http://localhost:5000` adresine yönlendirir.

Netlify yayın klasörü: `frontend/dist`

Yeni frontend Netlify'a alındığında proje taban dizini `frontend` seçilmelidir. Bu
klasördeki `netlify.toml` mevcut kök prototipin ayarlarını etkilemez.
