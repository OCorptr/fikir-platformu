## 🔄 Kritik veri akışları

### 1. Login + MFA akışı

```
Yetkili Girişi (Modal)
  │
  ▼
POST /api/auth/captcha/new       → captchaId, captchaImage/question
  │
  ▼
POST /api/auth/login             → PreMfa cookie (HttpOnly)
  │ { captchaId, captchaAnswer, email, password }
  │ response: { mfaRequired:true, context:'ministry'|'province'|... }
  │
  ▼
GET  /api/auth/mfa/method        → { method:'Totp'|'Email', needsGmailOAuth:bool }
  │
  ├──► Totp: User enters 6-digit code
  │    POST /api/auth/mfa/verify → 200 + cookie
  │
  └──► Email:
       ├── if needsGmailOAuth: window.location = /api/auth/gmail-oauth/start?returnTo=/mfa-login
       │                        (OAuth callback → DB upsert encrypted refresh token → returnTo'ya redirect)
       └── else:
            POST /api/auth/mfa/send-email-otp → mail gönderilir
            POST /api/auth/mfa/verify → 200 + cookie
```

### 2. OAuth Handshake (Sistem Sabit Gmail)

```
Browser:
  /admin/oauth → "Gmail OAuth Handshake'i Başlat" button
       │
       ▼ window.location.href (NOT window.open — 3rd-party cookie engeli)
  GET /api/auth/gmail-oauth/start?returnTo=/admin/oauth
       │
       ▼ 302 redirect to Google OAuth consent
  Google:
       user: fikir.platformu.iletisim@gmail.com
       "İzin ver"
       │
       ▼ 302 redirect to backend callback
  GET /api/auth/gmail-oauth/callback?state=base64url&code=...
       │
       ├── verify state cookie (CSRF)
       ├── exchange code → refresh_token (POST https://oauth2.googleapis.com/token)
       ├── encrypt refresh token (PBKDF2)
       ├── DB upsert (Id=1, EncryptedRefreshToken, UpdatedAt)
       └── 302 redirect to /admin/oauth?gmail_oauth=ok

DB:
  gmail_refresh_tokens (Id=1)
    ├── EncryptedRefreshToken: <PBKDF2-encrypted>
    ├── Scope: "https://www.googleapis.com/auth/gmail.send"
    ├── SenderEmail: "fikir.platformu.iletisim@gmail.com"
    └── UpdatedAt: <now>

Sonraki /mfa/send-email-otp:
  GmailApiEmailSender → DB'den refresh token çöz → access token al → Gmail API send
```

### 3. Admin Şifre Reset

```
Admin Panel → /admin → 🔗 Şifre Reset (kullanıcı kartında)
       │
       ▼
POST /api/admin/users/{id}/reset-password
       │
       ├── Token üret (PBKDF2 random 32 byte)
       ├── DB insert (PasswordResetTokens: UserId, TokenHash, ExpiresAt, CreatedAt)
       ├── Gmail API ile HTML mail gönder (gmail_refresh_tokens.Id=1'den)
       │    Subject: "=?UTF-8?B?...?= Geleceğin Fikri — Şifre Sıfırlama"
       │    Body (HTML, base64 CTE): "Şifremi Sıfırla" button + reset link
       │
       ▼ Frontend → "Sıfırlama bağlantısı kullanıcının e-postasına gönderildi."
```

## 🔐 Authentication / Authorization

- **4 cookie scheme** (`Program.cs`): `IdentityConstants.ApplicationScheme` (öğrenci + yetkili giriş), `ProvinceScheme`, `MinistryScheme`, `PreMfaScheme` (login sonrası, MFA doğrulanmadan önceki yarım oturum).
- **MFA öncesi:** `PreMfaScheme` 10 dk geçerli; `/api/auth/mfa/*` bu cookie üzerinden çalışır, doğrulama sonrası hedef role'ün scheme'ine yükseltilir.
- **Yetkili Girişi** = yetkili cookie + MFA. Redirect paths:
  - `SystemAdmin` → `/admin` (Sprint 11.14)
  - `MinistryOfficial` → `/bakanlik`
  - `ProvinceManager` / `ProvinceEvaluator` → `/il-panel`
- **Öğrenci** = `ApplicationScheme` cookie, MFA gerekmez. `/fikir`.
- **Cross-context guard (Sprint 10):** bir scheme'de oturum açıkken diğer scheme'in modalinde form gizlenir (banner + Çıkış Yap). İki hesap aynı tarayıcıda aynı anda açık olamaz.
- **Admin scope privacy guard (Sprint 11):** `/api/admin/users*` Student rolü user'lara erişemez. Whitelist: SystemAdmin, MinistryOfficial, ProvinceManager, ProvinceEvaluator. Onur'un açık talimatı.

## 🔄 CORS pipeline (Microsoft Learn pattern)

```csharp
app.UseRouting();              // 1. routing
app.UseCors(...);              // 2. CORS (BEFORE auth!)
app.UseAuthentication();       // 3. identity cookie validation
app.UseAuthorization();        // 4. role/policy check
```

**Kritik hata (Sprint 10.7 öncesi):** `UseCors` `UseAuthentication`'dan sonra → preflight OPTIONS 401 alıyor, browser fetch sessizce bloklanıyor.

**Sprint 10.7 fix:** `UseCors` `UseAuthentication`'dan önce + `Cors__AllowedOrigins` env boşsa hardcoded production fallback `https://fikir-platformu-web.onrender.com` + dev `http://localhost:5173`.
